# 노션 → 블로그 자동 동기화

노션 데이터베이스에 글을 쓰면 GitHub Actions가 15분마다 읽어서
`posts/*.md` + `assets/images/notion/` 로 변환해 커밋한다.

**노션이 원본이다.** 동기화된 글을 admin에서 고치면 다음 동기화 때 덮어써지므로,
admin의 글 목록에서는 그런 글에 `노션` 배지가 붙고 수정 버튼 대신
"노션에서 편집" 링크가 나온다. admin에서 직접 쓴 글은 영향을 받지 않는다.

## 최초 설정 (한 번만)

### 1. 노션 데이터베이스 만들기

새 페이지에서 `/표` → **표 보기(Table)** 로 데이터베이스를 만들고 속성을 아래처럼 둔다.
(이름은 한글/영문 아무거나 — 괄호 안 이름들도 인식한다)

| 속성 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| 제목 | 제목(Title) | ✔ | 글 제목 |
| `Slug` (슬러그) | 텍스트 | ✔ | URL 주소. 영문 소문자·숫자·하이픈 (예: `2026-08-10-rnn-2`) |
| `카테고리` (Category) | 선택(Select) | | `AI/DeepLearning` 처럼 슬래시로 하위 카테고리 표현 |
| `태그` (Tags) | 다중 선택 | | |
| `요약` (Summary) | 텍스트 | | 비우면 본문 앞부분에서 자동 생성 |
| `발행` (Published) | 체크박스 | | **체크된 글만 블로그에 올라간다.** 속성이 없으면 전부 발행 |
| `썸네일` (Thumbnail) | URL 또는 파일 | | 비우면 페이지 커버 이미지 사용 |
| `날짜` (Date) | 날짜 | | 비우면 페이지 생성일 |

Slug를 비워두면 자동 생성되지만 주소가 지저분해지니 채우는 걸 권장.

### 2. 노션 인테그레이션 만들고 DB 연결

1. <https://www.notion.so/my-integrations> → **New integration** 생성
   (Capabilities는 **Read content** 만 있으면 된다)
2. 발급된 **Internal Integration Secret** (`ntn_...`) 복사
3. 만든 데이터베이스 페이지 → 우상단 `⋯` → **연결(Connections)** → 방금 만든 인테그레이션 추가

### 3. GitHub에 값 등록

저장소 → **Settings → Secrets and variables → Actions → New repository secret** 로 두 개 등록:

| 이름 | 값 |
| --- | --- |
| `NOTION_TOKEN` | 2번에서 복사한 `ntn_...` |
| `NOTION_DB_ID` | DB 주소의 32자리 ID |

DB ID는 데이터베이스를 전체 페이지로 연 뒤 주소에서 찾는다:
`https://notion.so/myworkspace/`**`1b2c3d4e5f6...`**`?v=...` — 물음표 앞 32자리.

### 4. 동작 확인

저장소 **Actions 탭 → 노션 동기화 → Run workflow** 로 즉시 실행해본다.
로그에 `↓ 글제목` 이 찍히고 커밋이 생기면 성공.

## 평소 사용법

1. 노션 DB에 새 행을 만들고 글을 쓴다
2. `Slug`, `카테고리` 를 채우고 `발행` 체크
3. 15분 안에 자동 반영 (급하면 Actions 탭에서 수동 실행 → 1~2분)

발행 체크를 해제하거나 행을 지우면 블로그에서도 글과 이미지가 함께 삭제된다.

## 변환 규칙

| 노션 | 블로그 |
| --- | --- |
| 제목1/2/3 | `##` / `###` / `####` (글 제목이 이미 h1이므로 한 단계 내림) |
| 인라인 수식 · 수식 블록 | `$...$` · `$$...$$` (KaTeX 렌더) |
| 콜아웃 | `> [!NOTE]` 등 — 아이콘(💡⚠️❗📌)과 색으로 종류 자동 판별 |
| 이미지 | 저장소로 내려받아 커밋 (노션 URL은 만료되므로) |
| 토글 | `<details>` 접기 블록 |
| 표 · 코드 · 인용 · 목록 · 체크박스 | 그대로 대응 |
| 컬럼 레이아웃 | 세로로 펼침 |
| 목차 · 하위 페이지 · DB 뷰 | 생략됨 |

## 주의

- 이미지 파일명은 내용 해시라서, 그림이 안 바뀌면 다시 동기화해도 커밋이 늘지 않는다
- 페이지 수정 시각이 그대로면 본문을 다시 받지 않는다 (API 호출 절약)
- GitHub은 **60일간 저장소 활동이 없으면 예약 워크플로를 자동 중지**한다. 그럴 땐 Actions 탭에서 다시 켜면 된다
- 로컬 테스트: `NOTION_TOKEN=... NOTION_DB_ID=... node sync.js`
