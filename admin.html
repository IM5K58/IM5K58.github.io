글 관리 시작하기

GitHub 토큰으로 이 블로그 저장소에 연결합니다.
토큰은 이 브라우저에만 저장돼요.

토큰 발급 방법 (한 번만 하면 됩니다)
  1. GitHub → Fine-grained token 발급 페이지 접속
  2. Repository access: Only select repositories → IM5K58.github.io만 선택
  3. Permissions → Repository permissions → Contents: Read and write만 부여
  4. 만료 기간 설정(90일 권장) 후 생성된 토큰을 위에 붙여넣기
이렇게 발급하면 토큰이 유출되더라도 피해 범위가 이 블로그 저장소로 한정됩니다. 공용 PC에서는 사용 후 꼭 로그아웃하세요.

내 글 관리

카테고리 관리

여기서 만든 카테고리를 글 쓸 때 선택할 수 있어요. 상위 카테고리를 고르면 그 아래 하위 카테고리로 만들어집니다. 글이 있거나 하위가 있는 카테고리는 삭제할 수 없습니다.

새 글 쓰기

영문 소문자·숫자·하이픈. 저장 후엔 변경할 수 없어요.
카테고리는 목록 화면의 카테고리 관리에서 추가할 수 있어요.
에디터 사용법 (노션처럼 쓰기)
  • / — 빈 줄 맨 앞에서 입력하면 블록 메뉴. 이어서 타이핑하면 검색 (한글·영문 모두: /제목, /h1, /code, /표)
  • 블록 이동/추가 — 블록에 마우스를 올리면 왼쪽에 ⠿ 드래그 핸들과 + 버튼이 떠요. +는 아래에 새 블록 추가
  • 블록 삭제 — 블록 다음 줄 맨 앞에서 Backspace → 블록이 파랗게 선택됨 → 한 번 더 누르면 통째로 삭제 (표·코드 블록도 동일)
  • 마크다운 단축 — # 제목, - 목록, > 인용구, ``` 코드, --- 구분선이 입력 즉시 변환
  • 수식 — $수식$ 인라인, /수식으로 블록. 입력 즉시 렌더
  • 콜아웃 — /콜아웃 삽입 후 NOTE를 TIP/IMPORTANT/WARNING/CAUTION으로 바꾸면 색이 바뀜
  • 표·이미지 — 웹/엑셀 표를 복사해 붙여넣으면 표로 변환, 스크린샷 붙여넣으면 자동 업로드
